# Бот-помощник на RAG по FastAPI документации + Qwen

Бот, отвечающий на вопросы по документации FastAPI и GitHub issues, ссылается на источник, полностью локален


## Общее описание

1. **Данные.** 155 md файлов документации FastAPI и 40 закрытых issues с ответами
2. **Ноды** по md заголовкам (MarkdownNodeParser, заголовки в ``` не считаются), внутри секции режем SentenceSplitter'ом до 400 токенов с overlap'ом в 50. Итого 2851 нода.
3. **Эмбеддинги** BAAI/bge-small-en-v1.5, хранение в Chroma, косинусное расстояние.
4. **Поиск по ключевым словам**. BM25 (bm25s, со стеммингом) по тем же нодам.
5. **Гибриддный поиск**. Берём по 30 кандидатов из каждого поиска и сливаем через QueryFusionRetriever (RRF, k=60)
6. **Реранкинг**. Кросс-энкодер ms-marco-MiniLM-L-6-v2 читает вопрос и кандидата вместе и пересортировывает 30 кандидатов в топ-5
7. **Генерация и эскалация**. Qwen2.5-3B-Instruct через Ollama отвечает только по найденным чанкам и возвращает ответ и уверенность по pydantic схеме, которая уходит в Ollama как format, так что формат ответа не ломается. Вопрос эскалируется, если confidence="low" или лучший скор после реранка ниже 0 
8. **Стек** llama-index (core, llms-ollama, embeddings-huggingface, vector-stores-chroma, retrievers-bm25), sentence-transformers, chromadb, ollama, transformers. Версия без фреймворка в предыдущем коммите

## Qwen без RAG и с RAG

Правильные ответы сверены с текстом документации в source_documents/.

**Как отключить OpenAPI и UI docs через переменную окружения?**

- Без RAG: выдумывает несуществующую переменную FASTAPI_DEBUG и инструкции export FASTAPI_DEBUG=false. В документации такой переменной нет.
- С RAG: "установите OPENAPI_URL в пустую строку, например OPENAPI_URL= uvicorn main:app". Это совпадает с документацией (how-to/conditional-openapi), но ссылку на источник модель не поставила.

**Что требуется от allow_origins/allow_methods/allow_headers при `allow_credentials=True?**

- Без RAG: длинный ответ с несуществующим классом CorsOrigiinStrategies.
- С RAG: "ни один из них не может быть ['*'], все надо указывать явно". Верно, источник tutorial/cors.

**Как настроить Redis Sentinel failover в Django?** (вопрос вне корпуса)

- Без RAG: пошаговая инструкция, как будто модель знает ответ.
- С RAG: confidence=low, "в предоставленном контексте нет информации", вопрос эскалирован человеку.

**Где система ошибалась.** В v1 на вопрос "как захостить JS и CSS для docs у себя" ответ был 1 3 4, то есть модель вернула номера чанков вместо текста, да ещё с confidence: high, и эскалации не случилось. В версии на LlamaIndex на этот вопрос приходит нормальный ответ

## Метрики

### Выдача

| Ретривер | Recall@5 | MRR |
|---|---|---|
| Dense | 95.3% (81/85) | 0.843 |
| + BM25 и RRF | 98.8% (84/85) | 0.912 |
| + Cross-encoder rerank | 97.6% (83/85) | 0.887 |

Основной прирост даёт гибрид, реранк на этом наборе ничего не добавляет (MRR 0.912 и 0.887). На первом наборе из 25 вопросов реранк выглядел полезнее, так что вывод про него нестабилен. В v1 на тех же вопросах получилось 91.8% / 0.812, 97.6% / 0.890 и 97.6% / 0.889: разница между версиями в пределах нескольких вопросов, то есть на качество поиска фреймворк не повлиял

**eval набор**. 85 случайных чанков документации (seed 42, длина больше 300 символов), для каждого Qwen пишет вопрос, на который чанк отвечает. Правильным ответом считается файл источник. Плюс 15 вопросов ловушек, написанных вручную, про Django, Kubernetes, BERT, AWS Lambda и столицу Монголии, ответов в корпусе на них нет. Вопросы сгенерированы по чанкам v1, для LlamaIndex-версии набор не пересобирался, чтобы сравнение было на тех же вопросах.

### Весь бот

| Метрика | Значение |
|---|---|
| Отвечаемые вопросы, на которые бот не эскалировал | 80/85 |
| Вопросы-ловушки вне корпуса, которые бот эскалировал | 15/15 |

В v1 было 74/85, причём 6 эскалаций из 11 были сбоями генерации (Ollama обрывал зациклившийся ответ). В версии на LlamaIndex сбоев генерации в этом прогоне нет

### Ограничения

- Вопросы сгенерированы моделью из самих чанков. Реальные вопросы будут сложнее, и разница между ретриверами там может быть другой, в том числе реранк может оказаться полезнее
- Совпадение считается по файлу, а не по чанку, метрика мягче настоящей
- Без temperature=0 Qwen нестабилен: один запуск дал 22/25 вместо 25/25, поэтому в боте temperature=0 и seed=0
- В v1 3B модель ломала JSON схему (вложенность полей). Сейчас схема уходит в Ollama как format и такого нет, но ссылки [n] на источник модель ставит не всегда

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.default .env

ollama pull qwen2.5:3b-instruct

python fetch_docs.py && python fetch_tickets.py
python index_documents.py && python build_bm25_index.py

python build_eval_set.py
python run_eval.py dense
python support_chatbot.py "How do I add a dependency to a path operation?"
```
